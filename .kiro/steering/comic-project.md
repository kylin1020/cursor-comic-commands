# Comic Project Steering

全局指导规则，适用于所有漫画/动漫生成项目。

## 多项目结构

```
workspace/
├── .kiro/steering/       # 全局指导规则
├── skills/               # 技能文件
├── projects/             # 所有漫画项目
│   ├── 小说名称1/        # 项目1
│   │   ├── TODO.md
│   │   ├── NOTE.md
│   │   ├── style.md
│   │   ├── characters/
│   │   ├── scenes/
│   │   ├── chapters/
│   │   └── outputs/
│   └── 小说名称2/        # 项目2
│       └── ...
└── README.md
```

## 单个项目结构

```
projects/{项目名}/
├── TODO.md               # 任务追踪
├── NOTE.md               # 分析记忆
├── style.md              # 风格定义 (必需)
├── characters/           # 角色定义文件
│   └── <name>.md
├── scenes/               # 场景定义文件
│   └── <name>.md
├── chapters/             # 分割后的小说章节
│   └── chapter_XXX.md
├── outputs/
│   ├── characters/<name>/  # 角色图像
│   ├── scenes/<name>/      # 场景图像
│   └── chapters/<name>/    # 分镜图像
└── updates_log.md        # 更新日志
```

## 角色文化背景

**默认: 中国/中式风格**，除非用户另有指定。

这决定了:
- 面部特征 (中国、日本、韩国、西方等)
- 服装和配饰中的文化元素
- 建筑和环境美学

## 动漫风格选项

- 日系动漫 (宫崎骏、新海诚、京都动画)
- 美式漫画 (漫威、DC)
- 中式动漫 (国风动漫)
- 韩式条漫
- 自定义混合风格

## 提示词书写标准

### 自然语言格式
- 使用完整句子，不要堆砌关键词
- 控制在 500 字 (中文) 或 800 词 (英文) 以内
- 顺序: 主体 → 文化背景 → 外貌 → 服装 → 表情 → 背景 → 风格 → 质量

### 历史人物增强
处理历史人物时:
1. 明确历史身份和成就
2. 强调独特的外貌特征
3. 突出权力属性和心理状态
4. 考虑时代适当的服装和场景

## 图像生成顺序

1. **基础参考图优先** (不使用参考图):
   - 角色正面照
   - 场景远景

2. **衍生图像** (使用基础图作为参考):
   - 三视图
   - 表情参考图
   - 动作参考图
   - 场景中景/近景

3. **分镜图像** (使用所有参考图):
   - 先生成前帧
   - 尾帧必须使用前帧作为参考

## 分镜连续性规则

镜头之间需要保持的七个方面:
1. **空间**: 位置一致性，180° 规则
2. **时间**: 时间/光线一致性
3. **动作**: 帧之间的姿势连续性
4. **视线**: 注视方向逻辑
5. **外观**: 服装/道具一致性
6. **光照**: 光源方向/强度
7. **环境**: 天气/背景元素
