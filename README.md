# 漫画生成助手 (Comic Generation Assistant)

一个交互式 AI 助手，帮助你将小说转换为漫画。支持多个小说项目同时管理。

## 🚀 快速开始

直接与 AI 对话，它会询问你想做什么:

```
👋 你好！我是漫画生成助手。

请选择你想要做的事情:

1️⃣ 新建项目 - 从小说创建新的漫画项目
2️⃣ 选择项目 - 切换到已有的漫画项目
3️⃣ 初始化小说 - 分割小说章节，分析角色和场景
4️⃣ 创建漫画设定 - 设置风格，生成角色和场景设定
5️⃣ 生成角色图像 - 生成角色正面照、三视图、表情、动作参考图
6️⃣ 生成场景图像 - 生成场景远景、中景、近景
7️⃣ 创建分镜脚本 - 为指定章节创建分镜
8️⃣ 生成分镜图像 - 生成分镜的前帧和尾帧
9️⃣ 添加角色/场景 - 为后续章节添加新角色或场景
🔟 查看项目状态 - 查看当前项目进度
```

## 📂 单个项目结构

```
projects/{项目名}/
├── TODO.md               # 任务追踪
├── NOTE.md               # 分析记忆
├── style.md              # 风格定义
├── characters/           # 角色设定文件
│   └── <角色名>.md
├── scenes/               # 场景设定文件
│   └── <场景名>.md
├── chapters/             # 分割后的小说章节
│   └── chapter_XXX.md
├── outputs/
│   ├── characters/<角色名>/  # 角色图像
│   ├── scenes/<场景名>/      # 场景图像
│   └── chapters/<章节名>/    # 分镜图像
└── updates_log.md        # 更新日志
```

## 📋 工作流程

### 完整流程

1. **新建项目** → 创建项目目录
2. **初始化小说** → 分割章节，分析内容
3. **创建漫画设定** → 设置风格，生成设定
4. **生成角色图像** → 正面照、三视图、表情、动作
5. **生成场景图像** → 远景、中景、近景
6. **创建分镜脚本** → 为章节创建分镜
7. **生成分镜图像** → 前帧、尾帧

## 🎨 支持的风格

### 文化背景 (默认: 中国/中式)
- 中国/中式 - 中国面部特征、中国文化元素
- 日本/日式 - 日本面部特征、日本文化元素
- 韩国/韩式 - 韩国面部特征、韩国文化元素
- 西方/欧美式 - 西方面部特征、西方文化元素

### 动漫风格
- 日系动漫 (宫崎骏、新海诚、京都动画)
- 美式漫画 (漫威、DC)
- 中式动漫 (国风动漫)
- 韩式条漫
- 自定义混合风格

## 💬 快捷命令

- `项目` / `列表` - 列出所有项目
- `状态` / `进度` - 查看当前项目状态
- `帮助` / `help` - 显示帮助信息
- `继续` - 继续上次的任务

## 📝 任务追踪

每个项目使用独立的 `TODO.md` 追踪任务进度:
- `[ ]` - 待完成
- `[x]` - 已完成
- `🤖` - 委托给 Sub-agent 执行

## 🔧 技术说明

- 使用 Kiro steering 文件管理工作流
- 支持 Sub-agent 委托执行复杂任务
- 状态驱动的任务管理
- 多项目独立管理
