# 技能: 添加角色/场景

向已初始化的漫画项目添加新角色或场景。

## 触发条件
- 项目已通过 init-comic 初始化
- 故事进展中出现新角色或场景

## 前置检查

确认以下文件/目录存在:
- `style.md` (风格定义)
- `characters/` 目录
- `scenes/` 目录

如果项目未初始化，提示用户先运行 `init-comic`。

## 执行流程

### 1. 询问添加类型
- **仅添加角色** - 新出现的角色
- **仅添加场景** - 新出现的地点
- **同时添加角色和场景** - 新元素一起出现

### 2. 收集信息

#### 添加角色时询问:
- 角色名称
- 基本信息: 年龄、性别、身份、职业
- 外貌特征: 发型、发色、眼色、脸型、身材、身高
- 服装设计: 日常服装、特殊服装、配饰
- 性格特点: 性格描述、说话风格、行为习惯
- 角色关系: 与现有角色的关系
- 出场章节: 首次出场和主要活跃章节

#### 添加场景时询问:
- 场景名称
- 场景类型: 室内/室外、城市/乡村、公共/私人等
- 环境描述: 建筑风格、装饰特点、空间布局
- 氛围特点: 光线、色调、天气、时间段
- 关键元素: 标志性物品、特殊装饰
- 功能说明: 场景在故事中的作用
- 出场章节: 首次出场和主要使用章节

### 3. 创建文件

#### 角色文件: `characters/<角色名>.md`
- 读取 `style.md` 确保风格一致
- 生成 4 个 AI 提示词 (正面照、三视图、表情、动作)
- 创建输出目录 `outputs/characters/<角色名>/`

#### 场景文件: `scenes/<场景名>.md`
- 读取 `style.md` 确保风格一致
- 生成 3 个 AI 提示词 (远景、中景、近景)
- 创建输出目录 `outputs/scenes/<场景名>/`

### 4. 更新日志

创建或更新 `updates_log.md`:

```markdown
# 项目更新日志

## YYYY-MM-DD - 新增角色/场景

### 新增角色
- **角色名1** - 简短描述，首次登场章节
- **角色名2** - 简短描述，首次登场章节

### 新增场景
- **场景名1** - 简短描述，首次出场章节
- **场景名2** - 简短描述，首次出场章节

---
```

## 提示词生成要求

- 严格遵循 `style.md` 定义的风格
- 使用自然语言描述，500字(中文)或800词(英文)以内
- 包含完整的外貌、服装、动作、表情、背景、风格描述
- 与现有角色/场景保持风格一致

## 输出展示

完成后展示:
1. **新增内容列表** - 所有新创建的角色和场景
2. **文件创建确认** - 显示创建的文件路径
3. **AI提示词预览** - 展示部分生成的提示词示例
4. **输出目录确认** - 列出创建的输出目录
5. **后续步骤建议**:
   - 使用 `generate-images` 生成新角色参考图
   - 使用 `generate-images` 生成新场景参考图
   - 如需在特定章节使用，可创建或更新分镜脚本

## 注意事项

1. **保持风格一致**: 所有新内容必须严格遵循 `style.md`
2. **检查重复**: 创建前检查是否已存在同名角色/场景
3. **记录关系**: 记录新角色/场景与现有元素的关系
4. **章节追踪**: 明确记录首次出场和主要活跃章节
5. **提示词质量**: 确保提示词详细且符合 AI 图像生成最佳实践
