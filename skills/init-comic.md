# 技能: 初始化漫画项目

创建完整的漫画生成项目结构。

## 触发条件
- 用户要初始化新的漫画项目
- 已有小说分析信息 (来自 summarize-novel)

## 执行流程

### 阶段 1: 信息收集

#### 如果用户已提供 summarize-novel 输出
- 直接解析格式化信息
- 跳过分析步骤

#### 如果用户未使用 summarize-novel
询问用户提供:
1. **故事总结** (300-500字)
2. **主要角色** (3-8个): 姓名、年龄、外貌、性格、服装
3. **主要场景** (3-10个): 名称、环境描述、氛围

### 阶段 2: 确认风格

#### 角色文化背景 (关键!)
询问用户:
- **中国/中式** (默认) - 中国面部特征、中国文化元素
- 日本/日式 - 日本面部特征、日本文化元素
- 韩国/韩式 - 韩国面部特征、韩国文化元素
- 西方/欧美式 - 西方面部特征、西方文化元素
- 混合/其他

**如果用户不指定，默认使用中国/中式**

#### 动漫风格
询问用户:
- 日系动漫 (宫崎骏、新海诚、京都动画等)
- 美式漫画 (漫威、DC等)
- 中式动漫 (国风动漫)
- 韩式条漫
- 自定义

#### 历史人物项目 (如适用)
- 确认是否强调历史准确性
- 确认外貌处理方式: 完全按历史记载 vs 理想化改造
- 确认是否保留特殊外貌特征

### 阶段 3: 创建项目结构

```
project-root/
├── style.md
├── characters/
│   └── <角色名>.md
├── scenes/
│   └── <场景名>.md
├── chapters/
├── outputs/
│   ├── characters/<角色名>/
│   ├── scenes/<场景名>/
│   └── chapters/
├── README.md
├── TODO.md
└── NOTE.md
```

### 阶段 6: 创建 style.md

```markdown
# 项目风格定义

## 文化背景
- 角色文化背景: [中国/日本/韩国/西方]
- 建筑风格: [对应文化的建筑特点]
- 服装风格: [对应文化的服装特点]

## 动漫风格
- 风格类型: [日系/美式/中式/韩式]
- 参考作品: [具体参考]
- 线条风格: [描述]
- 色彩风格: [描述]

## 色彩方案
- 主色调: [颜色列表]
- 辅助色: [颜色列表]
- 强调色: [颜色列表]

## 光影处理
- 光源原则: [单光源/多光源]
- 对比度: [高/中/低]
- 阴影风格: [硬边/软边]

## 线条规范
- 主角轮廓: 2-3px 清晰锐利
- 细节线条: 0.5-1px 精细
- 背景线条: 0.25-0.5px 柔和

## AI生成通用关键词
### 中文
高质量精细画面，线条清晰，色彩明亮，光影对比强烈

### 英文
high quality, detailed, sharp lines, vibrant colors, 
strong lighting contrast, masterpiece, best quality
```

## 输出展示

完成后展示:
1. **项目结构概览** - 目录树
2. **创建的角色列表** - 基本信息和提示词预览
3. **创建的场景列表** - 描述和提示词预览
4. **后续步骤建议**:
   - 使用 `generate-images` 生成角色参考图
   - 使用 `generate-images` 生成场景参考图
   - 使用 `add-character-scene` 添加新角色/场景
   - 使用 `storyboard-chapter` 创建分镜脚本

## 注意
- 所有文件创建在 `projects/{项目名}/` 目录下
- 角色文件: `projects/{项目名}/characters/<角色名>.md`
- 场景文件: `projects/{项目名}/scenes/<场景名>.md`
- 输出目录: `projects/{项目名}/outputs/`
