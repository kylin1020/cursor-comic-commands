# 技能: 分割小说章节

将小说 txt 文件按章节分割成独立的 .md 文件。

## 触发条件
- 用户提供小说 txt 文件路径
- 需要将长篇小说分割成章节

## 执行流程

### 1. 读取和分析
```
1. 确认 txt 文件路径
2. 检测文件编码 (UTF-8, GBK, GB2312 等)
3. 预览前 50-100 行
4. 识别章节分隔模式
```

### 2. 章节识别模式

```python
# 中文数字章节
r'^第[一二三四五六七八九十百千零0-9]+章'

# 阿拉伯数字章节
r'^第\s*\d+\s*章'

# 英文章节
r'^Chapter\s+\d+'

# 卷/部分
r'^第[一二三四五六七八九十百千零0-9]+[卷部]'

# 带标题的章节
r'^第\d+章\s+.+'
```

### 3. 确认分割策略
- 显示识别到的章节数量
- 展示前 5-10 个章节标题示例
- 让用户确认或调整

### 4. 执行分割
```bash
# 输出目录
chapters/

# 文件命名
chapter_001.md, chapter_002.md, ...

# 文件格式
# 第一章 开端

（章节内容...）
```

### 5. 生成索引
创建 `chapters/README.md`:
- 章节总数统计
- 所有章节目录列表
- 每章字数统计 (可选)

## 输出示例

```
✅ 章节分割完成!

📊 统计:
- 原始文件: novel.txt (1.2 MB)
- 识别章节: 156 章
- 输出目录: chapters/
- 生成文件: 156 个 .md 文件
- 索引文件: chapters/README.md

📁 输出文件列表 (前 10):
  chapter_001.md - 第一章 开端
  chapter_002.md - 第二章 相遇
  ...
```

## 常见问题处理

| 问题 | 解决方案 |
|------|----------|
| 章节识别不准确 | 让用户提供正确的章节标题示例 |
| 文件编码错误 | 使用 chardet 自动检测编码 |
| 章节内容缺失 | 保留空章节文件，标注"待补充" |
| 文件名冲突 | 询问是否覆盖或添加时间戳 |
